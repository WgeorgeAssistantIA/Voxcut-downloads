# VoxCut – Silence Remover for Audio & Video

**VoxCut** automatically detects and removes silences, pauses and dead air from audio and video files (podcasts, interviews, courses, YouTube videos). Everything runs **100% locally**: no upload, no account, no subscription.

- Website: https://voxcutpro.com
- Windows & Linux: installers in the [Releases](https://github.com/WgeorgeAssistantIA/voxcut-downloads/releases) of this repository
- Microsoft Store: https://apps.microsoft.com/detail/9NP0N8W3DG5C
- Snap Store (Linux): https://snapcraft.io/voxcut
- Android: https://play.google.com/store/apps/details?id=fr.voxcut.voxcut_android

This repository only hosts the download files. VoxCut (voxcutpro.com) is made by La Fabrik Numérique (France) and is not related to other products using the VoxCut name (voxcut.org, voxcut.ai, voxcut.app).

---

**VoxCut** supprime automatiquement les silences, pauses et temps morts de vos fichiers audio et vidéo. Tout est traité **en local** : aucun envoi, aucun compte, aucun abonnement. Ce dépôt contient uniquement les fichiers de téléchargement proposés sur [voxcutpro.com](https://voxcutpro.com).
